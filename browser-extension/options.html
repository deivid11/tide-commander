Tide Commander — Error Trigger

Capture browser errors, chat with the agent assigned to a page, and pick DOM elements as context.

Commanders

Each Tide Commander server you connect to (by IP/host + optional token). The active one is the default; per-page agent assignment is remembered automatically from the chat panel.

Chat panel

Capture

Captured errors are listed in the chat panel's ⚠️ tray; nothing is sent to an agent until you press Send on a specific error.

Agent browser control

Lets a connected Tide Commander server read the live page (DOM, console, network, screenshots) and drive it (click, type, navigate) through /api/browser/*, in your real session. Uncheck to fully disable this — the chat panel stops registering and refuses every command. Driving still requires the side panel open and the debugger permission; only pages in the allowlist below can be controlled.
